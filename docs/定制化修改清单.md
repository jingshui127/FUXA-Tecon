### #TC-010: 自重启功能实现

- **文件路径**:
  - `server/runtime/index.js` (第498-535行)
  - `artifacts/启动FUXA.bat` (新增)
- **修改类型**: P2 - 功能增强
- **修改日期**: 2026-06-05
- **修改人**: 科控物联开发团队
- **修改原因**: 解决启用Node-RED后保存设置导致应用退出的问题，实现FUXA自动重启功能

**背景问题**:
- 启用Node-RED后，保存设置会触发 `restart()` 函数
- FUXA原生 `stop()->start()` 内部重启机制在 pkg 打包模式下不可靠
- 进程退出后无法重新启动，导致应用直接关闭

**解决方案 — 双重重启机制**:

| 方式 | 机制 | 触发条件 |
|------|------|---------|
| Method 1 | 写入 `_restart.flag` 文件 | `启动FUXA.bat` 检测到文件后循环重启 |
| Method 2 | `spawn(exePath)` 直接启动新进程 | 双击exe运行时自动重启 |

**核心代码** (`server/runtime/index.js`):
```javascript
// pkg模式下的外部重启逻辑
if (isPkg) {
    stop().then(function () {
        // Method 1: 写入flag文件供bat脚本检测
        fs.writeFileSync(path.join(workDir, '_restart.flag'), new Date().toISOString());

        // Method 2: spawn新exe实例（独立于父进程）
        var child = spawn(exePath, [], {
            detached: true,
            stdio: 'ignore',   // 注意：pkg限制，无法显示控制台日志
            cwd: workDir
        });
        child.unref();
        process.exit(0);
    });
}
```

**启动脚本** (`artifacts/启动FUXA.bat`):
```batch
@echo off
:loop
"FUXA-single-1.3.3-tecon-windows-x64.exe"
if exist "_restart.flag" (
    del "_restart.flag"
    timeout /t 2 /nobreak >nul
    goto loop
)
pause
```

**技术探索历程** (共13个版本迭代):

| 版本 | 方案 | 结果 |
|------|------|------|
| v1-v2 | exit code 10 + bat检测 | ❌ pkg无法传递退出码 |
| v3 | _restart.flag 文件信号 | ✅ 成功（依赖bat） |
| v4-v5 | spawn隐藏CMD + 延迟 | ❌ bat未执行 |
| v6-v7 | 动态生成bat + shell:true | ❌ bat残留不删除 |
| v8 | 移除windowsHide | ❌ 部分成功 |
| v9 | **直接 spawn(exe)** | ✅ 最终方案 |
| v10 | stdio重定向到文件 | ✅ 但窗口无文字 |
| v11 | stdio:'inherit' | ❌ 父进程退出崩溃 |
| v12 | cmd /c start | ❌ 不执行 |
| v13 | 回退v9稳定版 | ✅ **当前版本** |

**使用方式**:

| 启动方式 | 场景 | 重启 | 日志显示 | 推荐度 |
|---------|------|------|---------|--------|
| **StarAgent** | 生产部署 | ✅ 自动守护 | ✅ 正常 | ⭐⭐⭐ 生产 |
| 双击 `启动FUXA.bat` | 批量测试 | ✅ 自动重启 | ✅ 窗口实时 | ⭐⭐⭐ 测试 |
| 双击 exe | 快速验证 | ✅ 自动重启 | ⚠️ 黑窗口 | ⭐ 可用 |

**生产部署架构** (StarAgent):
```
agent/Config/StarAgent.config:
  FileName="./node18/node.exe" Arguments="main.js" WorkingDirectory="../server/"
  
优势：
- StarAgent 守护进程，进程退出自动重启（Delay=3000ms）
- 完整控制台日志输出
- 无需 pkg 打包，无路径问题
- 适合 100+ 台设备批量部署
```

**已知限制**:
1. pkg 打包环境下，通过 `spawn` 启动的子进程无法获得独立的控制台输出（`stdio:'inherit'` 会导致崩溃）
2. 重启后的日志写入 `_appdata/_logs/fuxa*.log` 文件，可通过查看文件获取完整日志
3. 如需看到重启日志，建议使用 `启动FUXA.bat` 启动

- **影响范围**: 
  - FUXA 设置保存时的重启行为
  - Node-RED 启用/禁用操作
  - 所有触发 `restart()` 的场景
- **升级兼容性**: ✅ 完全兼容
  - 仅修改了 runtime/index.js 中的 restart() 函数
  - 不影响其他功能模块
- **回滚方案**: 恢复原始 restart() 函数逻辑
- **测试状态**: ✅ 已验证以下场景：
  - 通过 bat 脚本运行 → 保存设置 → 自动重启 → 日志正常显示
