# FUXA 品牌配置说明

## 概述

FUXA 支持通过 `brand.json` 文件自定义品牌信息，包括品牌名称、浏览器标题、Logo 等。

## 配置文件位置

在 FUXA 数据目录（`data/`）下创建 `brand.json` 文件。

EXE 部署时：
```
FUXA-master/
├── FUXA-1.3.4-2888-win-x64.exe
├── data/
│   ├── brand.json          ← 品牌配置
│   ├── _appdata/           ← 应用数据
│   └── ...
└── ...
```

## 配置项说明

```json
{
    "name": "TcScada",
    "title": "TcScada - 工业监控平台",
    "logo": "logo.svg",
    "favicon": "favicon.ico",
    "shortName": "TCS",
    "footer": "© 2026 TcScada"
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 品牌名称，显示在侧边栏、加载页、关于对话框 |
| `title` | string | 是 | 浏览器标签页标题 |
| `logo` | string | 否 | Logo 文件名（相对于 data/ 目录），设为 `null` 使用默认 Logo |
| `favicon` | string | 否 | 浏览器图标文件名（相对于 data/ 目录），设为 `null` 使用默认 favicon |
| `shortName` | string | 否 | 品牌短名称（预留字段） |
| `footer` | string | 否 | 页脚文字，显示在加载页、关于对话框、用户信息对话框、PDF 报表 header |

> **注意**：`logo` 和 `favicon` 的值是**文件名**（如 `"logo.svg"`），不是路径（不需要前导 `/`）。文件需放在 `data/` 目录下。

### 品牌化覆盖位置

| 位置 | 替换内容 |
|------|----------|
| 浏览器标签页 | `title` |
| 浏览器图标 | `favicon` 文件 |
| 加载页 Logo | `logo` 文件 |
| 加载页文字 | `{name} Loading...` |
| 加载页底部 | `footer` |
| 侧边栏标题 | `name` |
| 侧边栏 Logo | `logo` 文件（用户未自定义布局 Logo 时回退） |
| 编辑器「关于」对话框 | Logo / `name` / `footer` |
| 用户信息对话框底部 | `footer` |
| PDF 报表 header | `footer` |

## 重启生效

**修改 `brand.json` 后必须重启服务器才能生效**。品牌配置在服务器启动时一次性加载到内存，修改文件后不会自动重新加载。

启动日志会输出确认信息：
```
[Brand] Loaded brand config from ...data\brand.json: name="TcScada"
```

### 操作步骤

1. 编辑 `data/brand.json`
2. 重启服务器（停止当前进程，重新运行 `FUXA-1.3.4-2888-win-x64.exe -p 1881` 或重启 EXE）
3. 浏览器强制刷新（`Ctrl + Shift + R`）清除缓存

## 回退规则

如果 `brand.json` 不存在或格式错误，FUXA 将使用默认品牌配置：
- name: "FUXA"
- title: "FUXA"
- logo: null（使用默认 Logo）

## 技术实现

### 后端

- `server/brand.js` - 品牌配置模块
  - `loadBrand(userDir)` - 启动时查找并读取 `brand.json`（查找顺序：`<userDir>/brand.json` → `<userDir>/data/brand.json` → `<userDir>/../data/brand.json` → `<userDir>/../brand.json`）
  - `getBrand()` - 返回当前品牌配置
  - `getLogoPath()` / `getFaviconPath()` - 返回 Logo/favicon 文件路径
  - `injectBrandToHtml(html)` - 将品牌信息注入 index.html（替换 title、favicon、加载占位符、Logo、footer，注入 `window.__BRAND__`）
- `server/main.js` - 注册 API 端点（无需认证）：
  - `GET /api/brand` - 返回品牌配置 JSON
  - `GET /api/brand/logo` - 返回 Logo 文件
  - `GET /api/brand/favicon` - 返回 favicon 文件

### 前端

- `AppService`（`client/src/app/_services/app.service.ts`）
  - `BrandConfig` 接口定义
  - 从 `window.__BRAND__` 读取服务端注入的品牌配置
  - `getBrand()` / `getBrandName()` / `getBrandLogo()` 方法
- `SidenavComponent` - 侧边栏标题显示 `brandName`，Logo 回退到品牌 Logo
- `DialogInfo`（编辑器关于对话框）- 注入 AppService，显示品牌 Logo/名称/footer
- `DialogUserInfo`（用户信息对话框）- 注入 AppService，底部显示品牌 footer
- `ReportEditorComponent` - PDF 报表 header 使用品牌 footer

> 详见 `FUXA定制化优化指南.md` 第 2.12 节。

## 注意事项

1. Logo 和 favicon 文件需要放在 `data/` 目录下
2. 支持的图片格式：PNG、JPG、SVG、ICO
3. Logo 文件大小建议不超过 500KB
4. favicon 文件大小建议不超过 100KB
5. 修改后需要重启 FUXA 生效
