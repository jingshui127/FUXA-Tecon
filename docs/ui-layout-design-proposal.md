## 一、友商界面深度分析

### 1.1 界面结构解剖

```
┌─────────────────────────────────────────────────────────────┐
│  状态栏 (固定高度 ~50px)                                    │
│  [实时参数组] [品牌Logo] [日期时间] [报警图标]              │
├─────────────────────────────────────────────────────────────┤
│  主内容区 (可滚动)                                          │
│  ┌─ 分区标题 (浅灰底色) ─────────────────────────────────┐  │
│  │ ┌──────┬──────┬──────┬──────┬──────┐                │  │
│  │ │行标签│ 列1  │ 列2  │ ...  │ 列N  │ 表格布局       │  │
│  │ ├──────┼──────┼──────┼──────┼──────┤                │  │
│  │ │参数名 │[输入] │[输入] │      │[输入] │               │  │
│  │ └──────┴──────┴──────┴──────┴──────┘                │  │
│  └────────────────────────────────────────────────────────┘  │
│  [更多分区...]                                               │
├─────────────────────────────────────────────────────────────┤
│  底部导航栏 (固定 ~60px)                                     │
│  [主页][模板][设置][斜率][延时][高级][调模][返回]           │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 设计元素提取

| 维度 | 友商做法 | 评价 |
|------|---------|------|
| **布局结构** | 三段式：顶栏+内容+底导航 | ✅ 经典工业HMI，操作员熟悉 |
| **状态栏** | 深色背景(#333)，白字，紧凑排列6-8个核心参数 | ✅ 信息密度高，一目了然 |
| **分区方式** | 浅灰标题栏 + 白底内容区 | ⚠️ 视觉层次偏弱 |
| **表格布局** | 行标签左对齐 + 输入框等宽排列 | ✅ 参数密集场景最优解 |
| **导航方式** | 底部图标导航(8个入口) | ⚠️ 入口过多，图标辨识度低 |
| **色彩体系** | 深灰+浅灰+白+绿色开关 | 🟡 功能性够用但缺乏品牌感 |
| **曲线图** | 内嵌页面中，带开关控制 | ✅ 数据与参数同屏对比 |

### 1.3 优势总结（市场验证有效）

1. **表格化参数展示** — 阶段×物理量矩阵天然适合注塑工艺
2. **全局常驻状态栏** — 核心工艺参数始终可见
3. **底部固定导航** — 单手拇指可达，站立操作友好
4. **曲线图内嵌** — 设定值vs实际值直观对比
5. **禁用态灰显** — 无效参数视觉弱化

### 1.4 问题诊断（差异化机会）

| # | 问题 | 严重度 | 说明 |
|---|------|--------|------|
| P1 | **空间利用率不均** | 🔴 | 设置页右侧大面积空白 |
| P2 | **信息层级扁平** | 🔴 | 所有参数同等权重，关键值不突出 |
| P3 | **导航过载(8个)** | 🟡 | 图标抽象，学习成本高 |
| P4 | **缺乏操作引导** | 🟡 | 无流程指示，新手迷茫 |
| P5 | **品牌识别弱** | 🟢 | 通用工业风，无记忆点 |
| P6 | **无响应式** | 🟡 | 固定尺寸，多屏体验差 |

## 二、信息架构与布局规划基础

### 2.1 产品定位

| 维度 | 定义 |
|------|------|
| 产品类型 | 注塑机/压铸机 HMI 触控面板 |
| 目标用户 | 工艺工程师 / 操作员 |
| 核心场景 | 监控 → 调参 → 排障 → 换模 |
| 使用环境 | 10-15寸触控屏，站立操作 |
| 品牌调性 | 专业可靠 + 高效智能 |

### 2.2 功能模块映射

```
注塑机HMI功能全景
├── 📊 实时监控 (主页)
│   ├── 核心工艺参数 (位置/压力/速度/周期)
│   ├── 设备状态 (温度/计数/模式)
│   └── 报警信息条
│
├── 🔧 模板管理 (模板) ⭐ 最常用
│   ├── 合模参数表 (多段压力/速度/位置)
│   ├── 开模参数表 (多段压力/速度/位置)
│   ├── 实时曲线图 (设定vs实际)
│   └── 关键位置汇总
│
├── ⚙️ 参数配置 (5个子页)
│   ├── 设置 — 全局开关/默认输出
│   ├── 斜率 — 加减速曲线参数
│   ├── 延时 — 动作/阀延时时间
│   ├── 高级 — 特殊功能配置
│   └── 调模 — 自动/手动调模
│
└── 🎛️ 快捷功能
    ├── 手动控制
    ├── 报警处理
    └── 生产统计
```

### 2.3 设计原则

```
┌────────────────────────────────────────────────────────────┐
│                    核心设计原则                              │
├────────────────────────────────────────────────────────────┤
│                                                            │
│  1. 效率优先                                               │
│     → 常用操作 ≤ 2 步到达                                  │
│     → 关键参数始终可见                                      │
│                                                            │
│  2. 信息分层                                               │
│     → L1: 实时数据 (状态栏，最高优先级)                     │
│     → L2: 当前任务参数 (主区域)                             │
│     → L3: 配置/辅助 (折叠或次级页)                         │
│                                                            │
│  3. 错误预防                                               │
│     → 输入范围限制                                         │
│     → 危险操作二次确认                                     │
│     → 异常值高亮                                           │
│                                                            │
│  4. 触控友好                                               │
│     → 触摸目标 ≥ 44px                                      │
│     → 数字键盘弹出输入                                     │
│     → 手势支持 (滑动/缩放)                                 │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

### 3.2 方案A vs 友商 对比改进

| 改进项 | 友商现状 | 方案A优化 | 收益 |
|--------|---------|----------|------|
| **空间利用** | 设置页右侧空白50% | 双列自适应网格布局 | 利用率↑40% |
| **信息层级** | 所有参数同等权重 | L1状态栏+L2主区+L3折叠 | 认知负荷↓30% |
| **导航** | 8个平铺按钮 | 主4+次4分组，当前页高亮 | 找寻效率↑50% |
| **快捷操作** | 无 | 页面级[保存/复制/导入]按钮 | 操作步数↓2 |
| **曲线图** | 占据固定空间 | 可折叠面板 | 有效面积↑25% |
| **视觉层级** | 单一灰色系 | 分区标题用主题色条 | 扫视速度↑20% |
| **禁用格** | 浅灰背景 | 斜线纹理 + 降低透明度 | 语义更明确 |
