FUXA PRO 启动方式指南

两种启动方式怎么选、怎么操作、怎么停 —— 只讲运行，不讲组态。

适用版本：1.3.5-PRO
程序目录：…\artifacts\
默认端口：1881
技术支持：QQ 2492123056

1先认识程序目录里的两个文件

文件作用
FuxaPro.exeFUXA 本体。双击它就会启动监控服务并打开网页界面，默认端口 1881。
Agent.exe配套的「进程守护」工具。可选，用来实现开机自动启动和程序崩溃后自动重启。
只想现在用一次 → 方式一

双击 FuxaPro.exe。简单直接，关掉窗口就停。

装到现场长期跑 → 方式二

双击 一键安装服务.bat。开机自启、崩溃自动重启，不需要人管。

2两种方式对比

对比项方式一：直接运行 FuxaPro.exe方式二：用 Agent.exe 守护
怎么启动双击 FuxaPro.exe双击 一键安装服务.bat（安装一次即可）
需要管理员权限不需要需要（脚本会自动提权，点「是」即可）
开机自动启动不支持支持。以系统服务方式启动，无需登录桌面
崩溃后自动重启不支持，需要人工重新打开支持。约每 10 秒检测一次，异常退出后自动拉起
怎么停止在窗口按 Ctrl+C，或直接关闭窗口双击 一键卸载服务.bat
适用场景调试、临时查看、单人在自己电脑上使用现场设备长期运行、无人值守
一句话结论 只要设备需要在断电重启、程序异常之后自己恢复，就用方式二。方式一适合调试和临时使用。

4方式二：用 Agent.exe 实现开机自启 + 后台守护

4.1 安装（推荐：一键脚本）

  1. 双击 一键安装服务.bat 会弹出「用户账户控制」窗口，点击「是」授予管理员权限。
  2. 等待约 20 秒 脚本会自动完成安装并打印服务状态，看到下面这行即为成功： 
            STATE              : 4  RUNNING
  3. 打开浏览器确认 访问 http://127.0.0.1:1881/，页面能正常打开即可。
安装一次就够了 安装后程序会随电脑开机自动启动，不需要再手动双击 FuxaPro.exe，也不需要登录桌面。

4.2 怎么确认装好了

检查项查看方法
服务按 Win+R 输入 services.msc，找到服务 StarAgent（显示名「进程守护」），状态应为「正在运行」。
进程打开任务管理器，能看到 FuxaPro.exe 正在运行。
网页http://127.0.0.1:1881/ 可以打开。
日志程序目录 Log\ 下的当天日志文件，出现 [1/FUXA]启动成功！PID=…。

4.3 停止 / 卸载

双击 一键卸载服务.bat，确认后等待约 15 秒即可。脚本卸载完服务后，若检测到程序仍在运行，会再询问一次是否一并结束进程。

卸载后程序还会“自己回来”（已实测） 卸载服务只解除开机自启和外部守护，不会结束已经在运行的 FuxaPro。而且 FuxaPro.exe 本身是双进程结构：一个守护进程（内存约 24 MB、不占端口）负责崩溃后自动重启，另一个服务进程占用 1881 端口。只结束占端口的那个，守护进程会在 2 秒内重新拉起一个新的，看起来就像“卸载无效”。
正确做法是结束整棵进程树：taskkill /F /T /IM FuxaPro.exe；或在任务管理器里找到占用内存较小、不占端口的那个 FuxaPro 结束它。
卸载不会删除 data\ 数据目录，也不会删除 customization\ 品牌目录。

4.4 临时守护（不安装服务）

如果只是想让程序在自己电脑上多一层保护，又不想装系统服务，可以走「模拟运行」：

  1. 双击 Agent.exe 会打开一个控制台窗口并列出菜单，其中第一项就是当前状态： 
    服务：进程守护(StarAgent)
状态：WindowsService 未安装（普通用户）

 8、  停止子服务      -StopService

请输入命令序号：
  2. 按数字键 5（模拟运行 / -run） 这时才会真正拉起并守护 FuxaPro.exe。注意：光双击 Agent.exe 是不会启动 FUXA 的，必须按 5。
  3. 关闭控制台窗口即停止守护 「模拟运行」只在当前窗口有效，退出窗口守护就结束；需要长期运行请用 4.1 的安装方式。

5安装守护时到底做了什么

项目说明
服务名 / 显示名StarAgent / 「进程守护」
运行账户LocalSystem（本地系统账户），启动类型为自动 —— 开机即启动，不需要用户登录桌面
守护对象同目录下的 FuxaPro.exe，检测间隔约 10 秒
配置位置程序目录 Config\（Agent.config、StarAgent.config）
运行日志程序目录 Log\
系统要求需要 .NET Framework 4.6.1；Windows 7 及以上系统已自带，通常无需另行安装

7常见问题

双击 FuxaPro.exe 后窗口一闪就没了

多半是 1881 端口被占用（提示 EADDRINUSE）。两种处理：换端口启动 —— 

FuxaPro.exe -p 1882

或者找出并结束占用 1881 的程序：

netstat -ano | findstr :1881
taskkill /PID 进程号 /F

如果是 FUXA 自己占着，只杀这一个 PID 会被守护进程在 2 秒内重新拉起，必须整棵树一起结束：

taskkill /F /T /IM FuxaPro.exe

浏览器打不开页面

  • 确认服务已启动（控制台出现 WebServer is running，或「进程守护」服务正在运行）。
  • 用 http://127.0.0.1:1881，不要用 localhost。
  • 别的电脑访问这台机器时，需要在 Windows 防火墙放行 TCP 1881 端口。

装完服务，重启电脑后页面打不开

先看 services.msc 里「进程守护」是否还在、是否被安全软件禁用或删除。若被拦截，请把程序目录加入杀毒软件白名单后重新执行 一键安装服务.bat。

想更换端口

编辑程序目录 Config\StarAgent.config，在 <Arguments> 里加上 -p 1882，保存后在 services.msc 里重启「进程守护」服务即可。

换一台电脑使用

把整个 artifacts 文件夹一起拷贝过去（含 FuxaPro.exe、Agent.exe、Config\、data\、Log\），在新电脑上重新双击 一键安装服务.bat。
