## 三、解析逻辑

### 3.1 地址访问范围与表格编号对应关系

**核心规律**：每个Excel工作表的地址访问范围遵循 `Dn000-Dn999` 的规律，其中 `n` 为表格编号。

| Excel工作表 | 地址访问范围 | 说明 |
|-------------|-------------|------|
| D0 | D0000-D0999 | D0寄存器区域 |
| D1 | D1000-D1999 | D1寄存器区域 |
| D2 | D2000-D2999 | D2寄存器区域 |
| D3 | D3000-D3999 | D3寄存器区域 |
| D4 | D4000-D4999 | D4寄存器区域 |
| D5 | D5000-D5999 | D5寄存器区域 |
| D6 | D6000-D6999 | D6寄存器区域 |
| D7 | D7000-D7999 | D7寄存器区域 |
| MD | MD0000-MD9999 | MD寄存器区域 |

**地址格式说明**：
- `D` + `n` + `xxx`：D前缀 + 表格编号 + 3位偏移量
- 示例：D3100 = D3工作表的第100个偏移量（3000+100=3100）
- 规律：`D3XXX` 对应 D3表格，`D4XXX` 对应 D4表格，以此类推

### 3.2 地址识别
- 正则表达式: `/^D\d{4}$/`
- 匹配格式: D + 4位数字（如D3100）
- 验证规则：前1位对应表格编号，后3位为偏移量（000-999）

### 3.3 列组结构
Excel工作表采用多列组并行布局，每列组包含：
- **地址列**: 存放D寄存器地址
- **分类列**: 分类名称（如"合模"、"开模"），跨行继承
- **参数列**: 具体参数名称
- **数据类型**: ushort(1字) 或 int(2字)（C#规范）

### 3.4 解析规则（简单直接）

解析逻辑非常简单：

**核心规则**：
1. **D*** 是 HMI 地址
2. **后面1-2个单元格合起来就是变量名称**（如果不是地址格式）
3. **根据参数单元格是否是合并单元格判断类型**（采用C#规范命名）：
   - **int类型**（2字）：参数单元格是**垂直合并**（跨2行），对应C#的int（32位有符号整数）
   - **ushort类型**（1字）：参数单元格是普通单元格（未合并），对应C#的ushort（16位无符号整数）

**示例1（D3100区域）**：
```
D3100 | 合模 | 电子尺行程 (H4-H5垂直合并) → 标签名: 合模电子尺行程, 类型: int, 字数: 2字
```

**示例2（D3140区域）**：
```
D3140 | 系统压 | 功能1 (普通单元格) → 标签名: 系统压功能1, 类型: ushort, 字数: 1字
D3141 |       | 测量值1 (普通单元格) → 标签名: 系统压测量值1, 类型: ushort, 字数: 1字
```

**示例3（D0107区域）**：
```
D0107 | 位置1 (垂直合并) → 标签名: 合模2位置1, 类型: int, 字数: 2字
```

**地址规则**：
- D0107（低字）+ D0108（高字）= 合模2位置1（int，2字）
- D3100（低字）+ D3101（高字）= 合模电子尺行程（int，2字）
- D3140 = 系统压功能1（ushort，1字）

### 3.5 分类继承规则

分类继承**仅在合并单元格范围内有效**：

```
行15: D0060 | 生产管理 | 设定模数 (合并单元格行15-24) → 标签名: 生产管理设定模数
行24: D0069 |        | 空 → 继承"生产管理"（在合并范围内）
行25: D0070 |        | 取样间隔 → 不继承"生产管理"（不在合并范围内）→ 标签名: 取样间隔
```

**关键规则**：只有当当前行在分类列的合并单元格范围内时，才继承分类值。

### 3.6 标签名生成规则
1. 如果有分类且分类≠参数名：`分类 + 参数名`
2. 如果无分类或分类=参数名：`参数名`
3. 重复标签名自动添加后缀：`标签名_1`, `标签名_2`...

### 3.7 地址转换规则
- **HMI地址**: D3100
- **Modbus(0-based)**: 4x3100 （保持寄存器，0索引）
- **FUXA地址**: 4X3101 （保持寄存器，1索引）

转换公式: `FUXA地址 = 4X + (HMI地址数字部分 + 1)`

## 四、关键处理逻辑

### 4.1 重复标签名处理
```javascript
let uniqueName = tagName;
let counter = 1;
while (tagNames.has(uniqueName)) {
    uniqueName = tagName + '_' + counter;
    counter++;
}
tagNames.add(uniqueName);
```

### 4.2 分类继承处理（基于合并单元格范围）
```javascript
function getCategoryForRow(rowIdx, colIdx) {
    for (const m of merges) {
        if (m.s.c === colIdx && m.e.c === colIdx && m.s.r !== m.e.r) {
            if (rowIdx >= m.s.r && rowIdx <= m.e.r) {
                const topLeftCell = sheet[XLSX.utils.encode_cell({ r: m.s.r, c: m.s.c })];
                if (topLeftCell && isValidCell(topLeftCell.v)) {
                    return topLeftCell.v.toString().trim();
                }
            }
        }
    }
    return '';
}
```

### 4.3 数据类型判断（基于合并单元格）
```javascript
function isVerticalMerge2(rowIdx, colIdx) {
    for (const m of merges) {
        if (rowIdx >= m.s.r && rowIdx <= m.e.r &&
            colIdx >= m.s.c && colIdx <= m.e.c &&
            m.e.r - m.s.r === 1) {
            return true;
        }
    }
    return false;
}
```

## 七、注意事项

1. **文件锁定**: Excel文件打开时可能无法复制，需先关闭Excel
2. **编码格式**: CSV文件使用UTF-8编码
3. **重复检测**: 自动处理重复标签名
4. **int处理**: 垂直合并单元格对应的高字地址会被自动跳过
5. **空值跳过**: 参数列为空的地址会被跳过
6. **类型规范**: 数据类型采用C#规范命名（int=32位有符号，ushort=16位无符号）
7. **分类继承**: 分类仅在合并单元格范围内有效，超出范围不继承
