科控物联 FUXA PRO 部署于现场控制室

科控物联 FUXA PRO 已经同步到官方 1.3.5。

这一版新增了配方管理、通用 EtherNet/IP 驱动，并修掉二十余项现场问题。

已经部署的现场可以平滑升级；还没上手的，文末有下载入口。

01

官方 1.3.5 新增了什么

配方管理是这一版的重头：支持从 PLC 上传和下载配方，带进度跟踪与取消，配方可以 CSV / JSON 导入导出，还新增了配方控件。

通用 EtherNet/IP 驱动上线，支持设备发现、I/O 模块配置和标签设置。

连接参数更可控：MQTT 与 Modbus 的连接超时可配置，MQTT 支持逐主题设置 retain。

脚本编辑器加入 JavaScript 语法校验，写完当场就能发现问题，不用等运行。

安全方面一并收口：认证、Node-RED 授权、DAQ 查询限制与设置泄露均已加固。

决定现场能不能长期跑下去的，
往往不是多了几个新功能，
而是那些“以前偶尔出、现在不再出”的问题。

所以 1.3.5 里更值得一看的，是这批修复：S7 布尔量写入 Bool 标签、客户端脚本每次 interval 重复执行、Modbus 与 OPC UA 写失败不上报、HMI 回车重复提交、Node-RED 基础路径下的路由与登出……都是现场真会碰到的。

02

科控 PRO 版在此之上做了什么

场景 科控 PRO 版
部署方式 单个 EXE 自带 Node.js 18 运行时，复制即用，免安装
品牌外观 内置科控物联 TcScada 品牌；EXE 同级 customization\ 目录可运行时替换 LOGO 与配置
通讯稳定性 S7 断线自动重连，单台设备异常不牵连其他设备
流程编排 Node-RED 提供 /flows 管理入口与 /dashboard 面板入口
开机自启 Agent.exe 进程守护，程序崩溃后自动拉起，附一键安装 / 卸载脚本
数据迁移 数据库、流程与插件集中在 data\，整目录搬迁即可
原生插件 ODBC、chartjs-node-canvas 已预置并实际验证

03

适合谁，不适合谁

适合：要把现场设备联网做集中监控；现场只有一台工控机、希望免安装部署；需要给最终用户换成自己的品牌；或者 S7 / Modbus / OPC UA / EtherNet/IP 多驱动混用。

不适合：只做一次性数据看板、不接现场设备；或者只想跑纯开源版、不希望附带守护服务。

已经部署的现场，可以直接升级到 1.3.5；还没上手的，可以先用一台工控机试装，跑通一个 Modbus 或 S7 设备再往下走。
