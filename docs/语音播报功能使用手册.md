# FUXA 语音播报功能使用手册

## 一、功能概述

FUXA 语音播报功能基于 Windows SAPI 实现，用于在报警触发和恢复时自动播报语音通知，帮助操作人员及时了解系统状态。

### 主要特性

- ✅ 报警触发时自动播报
- ✅ 报警恢复时自动播报
- ✅ 支持中文语音合成
- ✅ 播报队列机制，避免语音重叠
- ✅ 高高限报警优先播报
- ✅ 无需额外配置，开箱即用

## 二、系统要求

### 2.1 操作系统
- Windows 10 或 Windows 11
- Windows Server 2016 或更高版本

### 2.2 软件依赖
- Node.js 18.x
- PowerShell 5.1 或更高版本
- 中文语音包（Windows 11 默认已安装）

### 2.3 检查中文语音包

```powershell
# 检查已安装的语音
Add-Type -AssemblyName System.Speech
$synth = New-Object System.Speech.Synthesis.SpeechSynthesizer
$synth.GetInstalledVoices() | ForEach-Object {
    Write-Host "$($_.VoiceInfo.Name) [$($_.VoiceInfo.Culture.Name)]"
}
```

预期输出应包含：
- `Microsoft Huihui Desktop [zh-CN]` - 中文语音
- `Microsoft Zira Desktop [en-US]` - 英文语音

## 三、使用方法

### 3.1 自动播报（推荐）

**无需任何配置**，只需在 FUXA 中配置报警，当报警触发或恢复时会自动播报。

1. 启动 FUXA 服务器：
```powershell
cd server
npm start
```

2. 打开浏览器访问 `http://localhost:1881`

3. 在 FUXA 中配置设备和报警

4. 当报警触发时，系统自动播报：
   - 报警触发：`"注意，[报警名称][报警类型]报警"`
   - 报警恢复：`"[报警名称][报警类型]报警已恢复"`

### 3.2 报警类型播报内容

| 报警类型 | 播报文本 | 优先级 |
|---------|---------|--------|
| HIGH_HIGH (高高限) | 高高限 | 高 |
| HIGH (高限) | 高限 | 普通 |
| LOW (低限) | 低限 | 普通 |
| INFO (信息) | 信息 | 普通 |

### 3.3 播报示例

| 场景 | 播报内容 |
|------|---------|
| 温度传感器高限报警触发 | "注意，温度传感器高限报警" |
| 温度传感器高限报警恢复 | "温度传感器高限报警已恢复" |
| 压力传感器高高限报警触发 | "注意，压力传感器高高限报警"（优先播报） |

## 四、API 接口

### 4.1 获取语音播报状态

```powershell
Invoke-RestMethod -Uri "http://localhost:1881/api/alarms/speech/status" -Method Get
```

响应示例：
```json
{
  "enabled": true,
  "queueSize": 0,
  "isPlaying": false,
  "rate": 0,
  "volume": 100,
  "totalSpoken": 10,
  "errors": 0
}
```

### 4.2 禁用语音播报

```powershell
Invoke-RestMethod -Uri "http://localhost:1881/api/alarms/speech/disable" -Method Post
```

### 4.3 启用语音播报

```powershell
Invoke-RestMethod -Uri "http://localhost:1881/api/alarms/speech/enable" -Method Post
```

### 4.4 测试语音播报

```powershell
$body = '{"text":"测试语音播报"}'
[System.Text.Encoding]::UTF8.GetBytes($body) | Invoke-RestMethod -Uri "http://localhost:1881/api/alarms/speech/test" -Method Post -ContentType "application/json; charset=utf-8" -Body $body
```

### 4.5 配置语音参数

```powershell
$body = '{"rate":2,"volume":80}'
[System.Text.Encoding]::UTF8.GetBytes($body) | Invoke-RestMethod -Uri "http://localhost:1881/api/alarms/speech/config" -Method Post -ContentType "application/json; charset=utf-8" -Body $body
```

参数说明：
- `rate`: 语速，范围 -10 到 10，默认 0
- `volume`: 音量，范围 0 到 100，默认 100

### 4.6 获取可用语音列表

```powershell
Invoke-RestMethod -Uri "http://localhost:1881/api/alarms/speech/voices" -Method Get
```

## 六、故障排查

### 6.1 没有声音

**检查音频设备**：
```powershell
Get-CimInstance Win32_SoundDevice | Select-Object Name, Status
```

**检查音频服务**：
```powershell
Get-Service Audiosrv | Select-Object Name, Status
```

**检查默认音频设备**：
- 右键点击任务栏音量图标 → 打开音量混合器
- 确认默认输出设备是实际扬声器/耳机

### 6.2 中文乱码

确保系统已安装中文语音包：
```powershell
Add-Type -AssemblyName System.Speech
$synth = New-Object System.Speech.Synthesis.SpeechSynthesizer
$chineseVoices = $synth.GetInstalledVoices() | Where-Object { $_.VoiceInfo.Culture.Name -like "zh-*" }
Write-Host "中文语音数量: $($chineseVoices.Count)"
```

### 6.3 查看日志

```powershell
Get-Content "server\_logs\fuxa.log" -Tail 30
```

查找 `[Speech]` 相关日志。

## 八、技术实现

### 8.1 架构

```
报警触发 → _speakAlarms() → speech.speak() → 队列 → PowerShell SAPI → 音频输出
```

### 8.2 队列机制

- 最大队列长度：50 条消息
- 队列满时：丢弃最旧消息
- 高优先级消息：插入队列头部

### 8.3 性能指标

| 指标 | 数值 |
|------|------|
| 单次播报延迟 | 200-500ms |
| CPU 占用 | 5-15%（持续 1-3 秒） |
| 内存占用 | 20-50MB |
