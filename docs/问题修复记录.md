# 问题修复记录

## 2026-05-29: 下载小部件闪退问题

### 问题描述
在 fuxa-single.exe 打包版本中，下载小部件时 APP 直接闪退。

### 根本原因
pkg 打包后 `__dirname` 指向快照内部路径（如 `C:\snapshot\...\server`），导致以下两个问题：

1. **appDir 路径错误**：`settings.appDir = __dirname` 使得 appDir 指向快照内部
2. **userDir 传递错误**：`fuxa-single/main.js` 传递了 `fuxaDataDir`（包含 `_appdata`），导致 `workDir` 变成 `exeDir/_appdata/_appdata`

### 影响范围
- `server/api/resources/index.js` 中的 `removeWidget` API 使用 `runtime.settings.appDir` 进行路径安全检查
- pkg 打包后路径解析失败，导致 APP 闪退

### 修复方案

#### 1. 修改 main.js 中的 appDir 配置（4个文件）

将 `settings.appDir = __dirname;` 改为 `settings.appDir = rootDir;`

**涉及文件：**
| 文件路径 | 修改位置 |
|---------|---------|
| `server/main.js` | 第 104 行 |
| `fuxa-single/server/main.js` | 第 104 行 |
| `client/fuxa-single/server/main.js` | 第 104 行 |
| `tecon-patch/files/server/main.js` | 第 107 行 |

**修改前：**
```javascript
settings.appDir = __dirname;
```

**修改后：**
```javascript
settings.appDir = rootDir;
```

#### 2. 修改 fuxa-single/main.js 中的 userDir 传递（1个文件）

将 `userDir: fuxaDataDir` 改为 `userDir: exeDir`

**涉及文件：**
| 文件路径 | 修改位置 |
|---------|---------|
| `fuxa-single/main.js` | 第 47 行 |

**修改前：**
```javascript
console.log(`Launching FUXA server with userDir: ${fuxaDataDir}`);
const serverProcess = fork(serverPath, [], {
    env: { ...process.env, userDir: fuxaDataDir },
    stdio: 'inherit'
});
```

**修改后：**
```javascript
console.log(`Launching FUXA server with userDir: ${exeDir}`);
const serverProcess = fork(serverPath, [], {
    env: { ...process.env, userDir: exeDir },
    stdio: 'inherit'
});
```

### 验证方法

1. 重新打包：`pkg package.json --targets node18-win-x64 --out-path ../artifacts --public-packages "node-snap7,bindings,nan,@serialport/bindings-cpp"`
2. 运行 exe 文件
3. 检查日志输出：
   - `Using existing data directory: D:\...\artifacts\_appdata` ← 正确
   - `Launching FUXA server with userDir: D:\...\artifacts` ← 正确（不含 _appdata）
4. 测试下载小部件功能，不再闪退
