## P3级修改：组件逻辑增强（科控物联优化）

### #TC-005: Stardust APM性能监控集成 ⚠️

- **文件路径**:
  - `server/runtime/stardust.js` (新增)
  - `server/runtime/stardust-middleware.js` (新增)
  - `server/main.js` (修改)
- **修改类型**: P3 - 功能增强/第三方服务集成
- **修改日期**: 2026-04-15
- **修改人**: 科控物联开发团队
- **修改原因**: 添加应用性能监控(APM)，实现HTTP请求追踪和性能指标收集

**修改内容**:

1. **新增文件**:
   ```javascript
   // server/runtime/stardust.js - APM追踪器实现
   // 功能:
   // - 应用注册与心跳保活（每60秒）
   // - HTTP请求追踪（支持GZIP压缩）
   // - 性能指标统计（响应时间、错误率）
   ```

   ```javascript
   // server/runtime/stardust-middleware.js - Express中间件
   // 功能:
   // - 自动拦截HTTP请求
   // - 收集性能数据
   // - 上报到Stardust服务器
   ```

2. **修改文件** (`server/main.js`):
   ```javascript
   // 在Express app初始化后添加
   const stardustMiddleware = require('./runtime/stardust-middleware');
   app.use(stardustMiddleware());
   
   // 启动APM追踪
   require('./runtime/stardust');
   ```

- **功能特性**:
  - ✅ 应用注册与心跳保活
  - ✅ HTTP请求追踪（支持GZIP压缩）
  - ✅ 性能指标统计（响应时间、错误率）
  - ✅ 设备操作和告警处理追踪
  - ✅ 每60秒上报一次性能数据

- **配置信息**:
  ```
  Stardust服务地址: http://47.113.219.65:6600
  应用名称: FUXA-Server
  控制台地址: http://47.113.219.65:6600
  ```

- **影响范围**:
  - 服务端所有HTTP请求
  - 可能略微增加响应延迟（<5ms）
  - 网络流量增加（APM数据上报）

- **升级兼容性**: ⚠️ 需要适配
  - FUXA升级后需检查main.js的变更
  - Express中间件API可能变化
  - 需要重新集成到新的代码结构
  
- **回滚方案**:
  1. 删除 `server/runtime/stardust.js`
  2. 删除 `server/runtime/stardust-middleware.js`
  3. 从 `server/main.js` 移除stardust相关require和app.use调用
  4. 重启服务

- **禁用方法**（不删除代码）:
  - 注释掉main.js中的stardust引入
  - 或设置环境变量 `DISABLE_STARDUST=true`（需代码支持）

- **测试状态**: ✅ 已在生产环境运行
- **性能影响**:
  - CPU开销: <1%
  - 内存开销: ~10MB
  - 网络开销: ~50KB/分钟（取决于请求数量）

- **维护要求**:
  - 监控Stardust服务器可用性
  - 定期检查APM数据是否正常上报
  - 关注错误率异常告警

- **关联文档**:
  - [科控物联优化.MD](../科控物联优化.MD#七-stardust-apm-集成) - 详细说明
  - Stardust控制台: http://47.113.219.65:6600

**风险评估**: ⚠️ 中等风险
- 优点: 提供宝贵的性能监控能力
- 缺点: 修改了核心启动文件main.js
- 建议: 保持此修改，但确保有完善的监控和回滚机制
